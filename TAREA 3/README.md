## Descripción
Programa en Python que permite:
- Insertar datos
- Buscar elementos
- Eliminar nodos
- Cargar datos desde archivos CSV
- Visualizar el arbol usando Graphviz

## Requisitos
- Python 3
- Graphviz

Instalación:
pip install graphviz

## Ejecución
python main.py

## Archivos CSV
- ejemplo1.csv
- ejemplo2.csv
- ejemplo3.csv
